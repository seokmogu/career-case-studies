> 현재 상태: **공개용 정리본 · 2026-09-17 재검토**
> 회사 코드·원문 문서·내부 화면·고객 정보·미승인 지표를 복사하지 않았습니다. 사례별 공개 경계와 근거 상태를 함께 표시합니다.

[포트폴리오에서 전체 경력 보기](https://www.madebysmg.com)

## 어떤 사람인가

분산 시스템을 연구했고, 물류와 커머스를 직접 운영했으며, 도시·기업 데이터 제품을 만들었습니다. 지금은 웍스피어(잡코리아·알바몬 운영사)에서 Product Owner · AI Agent Platform Lead로 일하고 있습니다.

제품에 AI가 정말 필요한지부터 판단하고, 필요하면 데이터와 비용을 확인한 뒤 검토용 시제품을 직접 만들어 관련 팀과 다음 단계를 논의합니다.

## 케이스 작성 원칙

각 케이스는 동일한 순서로 작성합니다.

1. 문제와 사업·사용자 맥락
2. 내가 직접 맡은 판단과 책임
3. 연결한 데이터·시스템·조직
4. 주요 결정과 트레이드오프
5. 확인 가능한 변화 또는 산출물
6. 공개 근거와 비공개 경계

## 증거 표기

- **P — Public**: 공식 인터뷰, 공개 제품 자료, 공개 저장소처럼 제3자가 직접 확인할 수 있는 근거
- **I — Internal**: 본인이 작성한 기획안·의사결정 기록 등 직접 내부 산출물. 원문은 공개하지 않음
- **U — User-confirmed**: 본인이 직접 확인했지만 공개 원문이 없는 내용. 결과 주장에는 제한적으로 사용
- **H — Hold**: 역할·성과·공개 권한이 불명확해 공개하지 않는 내용

공개 제품의 존재를 개인의 출시 주도권으로 바꾸거나, 팀 결과를 개인 성과로 표현하지 않습니다. 자세한 기준은 [Evidence & Disclosure Policy](EVIDENCE_POLICY.md)에 기록합니다.

## 저장소의 범위

이 저장소는 회사 원본 코드의 공개판이나 미러가 아닙니다. 케이스 설명과 도식은 공개용으로 새로 작성한 재구성 자료이며, 실제 제품 아키텍처나 내부 운영 현황을 그대로 나타내지 않습니다.

별도 라이선스가 명시되지 않은 문서와 도식에 대한 사용 권한은 부여되지 않습니다.
